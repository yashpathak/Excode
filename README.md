# Excode

**Privacy-first local code execution environment**

Excode lets you write, run, and share code snippets and small scripts across multiple languages — entirely on your machine. No cloud execution by default. Built for developers who value speed, privacy, and simplicity.

## Why Excode?

Most online code runners send your code to remote servers. Excode runs everything locally first, giving you:
- Full privacy
- Offline capability
- Faster feedback loops
- A clean, distraction-free workspace

## Features (Current & Planned)

- Multi-language support (Python, JavaScript/TypeScript, Go, Rust, and more)
- Local sandboxed execution
- Instant run + output panel
- Snippet sharing (exportable links / files)
- Dark/light mode, minimal UI
- (Coming soon) AI-powered code explanation, debugging, and improvement suggestions
